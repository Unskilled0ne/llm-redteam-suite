# Security Policy

## Educational & Research Scope
This repository provides automated benchmarking tooling and defensive guardrails for large language model applications mapped to the OWASP Top 10 for LLMs. It is designed for security teams, model safety researchers, and developers evaluating defensive filters.

## Reporting Vulnerabilities
If you identify security bugs or bypasses in the defensive guardrails:
- **Do not** file public GitHub issues.
- Disclose responsibly to: **btsiamouras@gmail.com** or via [LinkedIn](https://www.linkedin.com/in/vasilis-tsiamouras/).
